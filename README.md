# 🌿 조용한 회복 공간

번아웃 및 정서 상태 점검을 돕는 **RAG 기반 상담 보조 챗봇**

---

## 프로젝트 소개

**Burnout_RAG**는 번아웃을 경험하는 대학생을 위한 한국어 AI 상담 보조 챗봇입니다.  
국내 학술 논문 24편을 기반으로 한 RAG(Retrieval-Augmented Generation) 파이프라인을 통해 문서 근거 기반 정보를 제공하며, RAG ON/OFF 토글로 두 방식의 답변을 직접 비교할 수 있습니다.

> ⚠️ 본 서비스는 의료 행위나 심리 치료를 대체하지 않습니다. 마음 온도는 진단이 아닌 참고용 UX 지표입니다.

---

## 주요 기능

- **체크인 & 마음 온도**: 6문항 설문(수면·활력·회복감·기분·스트레스·피로)으로 초기 마음 온도(0~100) 계산 및 시각화
- **RAG ON 답변**: BM25 + FAISS 하이브리드 검색으로 관련 논문을 찾고, Self-RAG로 검증한 뒤 문서 근거 기반으로 응답
- **RAG OFF 답변**: 검색·벡터DB 없이 LLM 자체 지식으로만 상담형 응답
- **RAG ON/OFF 토글**: 채팅 화면에서 즉시 전환하며 두 방식의 답변 차이를 비교 가능
- **위험도 분류**: 1인칭 위기 표현 감지 → 키워드 게이트 → 체크인 온도 기준으로 HIGH/MID/LOW 분류
- **안전 대응 우선**: 자해·자살·위기 신호 감지 시 상담 자원 자동 안내
- **적응형 응답 모드**: 위험 수준 × 대화 맥락에 따라 탐색/지지/안내/정보 모드로 자동 전환
- **사이드바 대시보드**: 마음 온도 링 차트, 현재 상태 배지, 체크인 요약 바, 오늘의 회복 팁

## 사용 흐름

```
① 온보딩: 닉네임 입력 → 아바타 선택
② 체크인: 6문항 설문 응답
③ 결과 확인: 마음 온도 + 위험 수준 + 개인화 메시지
④ 채팅 시작: RAG ON/OFF 선택 후 자유 대화
⑤ 사이드바: 대화 중 마음 온도와 체크인 요약 상시 확인
```

## RAG ON / RAG OFF 동작 비교

| 항목 | RAG ON | RAG OFF |
|------|--------|---------|
| 검색 방식 | BM25 + FAISS 하이브리드 → 임베딩 재랭킹 | 없음 |
| 답변 근거 | 검색된 논문 문서 기반 | LLM 자체 일반 지식 |
| Self-RAG 검증 | 지지도·유용성 자동 검증, 실패 시 재작성 | 없음 |
| 답변 구조 | 핵심 → 문서 기준 → 설명 → 주의점 → [근거 요약] | 간결한 상담형 응답 |
| 문서 외 정보 | `일반적으로는`으로 구분 표시 | 구분 없이 응답 |
| 근거 부족 시 | `검색된 문서만으로는 제한적입니다` 명시 | 해당 없음 |
| 대화 이력 | RAG 전용 세션 분리 | LLM 전용 세션 분리 |

## 설치 및 실행

### 1. 가상환경 생성 및 패키지 설치

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

pip install -r requirements.txt
```

### 2. 환경 변수 설정

`data/.env` 파일을 생성하고 OpenAI API 키를 입력합니다.

```env
OPENAI_API_KEY=sk-...
```

### 3. 앱 실행

```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501`로 접속합니다.

> **참고**: 최초 실행 시 FAISS 벡터 인덱스를 자동으로 빌드합니다. 수 분이 소요될 수 있습니다.

## 현재 한계

- 검색 문서의 범위와 품질에 따라 RAG ON 답변 품질이 달라질 수 있습니다.
- RAG ON 답변은 검색된 논문 문서 내용에 한정되며, 문서에 없는 정보는 보완 표시 후 제공됩니다.
- 마음 온도는 체크인 설문과 키워드 기반으로 계산되는 참고용 지표이며, 임상 진단이 아닙니다.
- 본 챗봇은 상담 보조용이며 전문 심리 치료를 대체하지 않습니다.
